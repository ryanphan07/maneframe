| Original ducked in quip window | -9.5 dB (filter is -10) | -9.5 dB |
| Commentary vs ducked original | +2.0 dB | +7.4 dB |
| Mix level in quip window vs 1.5 s before | -2.4 dB | +0.2 dB |
| Overlapping quips | none | none |
| Job time / first partial (API) | 168.8 s / 25.6 s | 176.4 s / 34.0 s |

Method: each quip is fitted into the decoded mix (lag and gain by correlation, 5 ms lag from AAC delay); the leftover is the ducked original. Overlap is from quip start plus decoded duration.

Finding (not fixed, mixing is a design call): edge quips sit at about -21 dB RMS against a source at about -13 dB, so commentary is only 1 to 4 dB above the ducked crowd, and the overall mix gets quieter during a quip. Piper is about 6 dB louder. Suggest normalizing quip loudness before mixing (a TASKS item for phase 1).
